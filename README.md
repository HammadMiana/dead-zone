# Dead Zone – 3D Shooting Game

**Dead Zone** is a 3D shooting game developed using the Unity Game Engine. The project was developed as a Final Year Project, with a focus on game development and interactive gameplay.

# About the Project

Dead Zone is a shooting game developed independently by me. I worked as the **Game Developer**, handling the development process using Unity and writing game scripts in C# with Visual Studio.

# Technologies Used

- **Game Engine:** Unity
- **Programming Language:** C#
- **Code Editor:** Microsoft Visual Studio
- **Version Control:** Git & GitHub

# Project Structure

- `Assets/` – Game assets and resources
- `Packages/` – Unity project packages and dependencies
- `ProjectSettings/` – Unity project configuration settings

#  Getting Started

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project** and choose the downloaded Dead Zone folder.
4. Open the project using a compatible Unity Editor version.
5. Open the game scene and run the project.
